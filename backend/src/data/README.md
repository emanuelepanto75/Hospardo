`comuni.json`: comuni italiani (anche soppressi) e stati esteri con il codice catastale usato nel codice fiscale.
Formato: `[codice, provincia (EE = estero), nome, 1 = attivo / 0 = soppresso o storico]`.

Fonte: ISTAT, tramite il pacchetto [codice-fiscale-js](https://github.com/lucavandro/CodiceFiscaleJS) di Luca Vandro,
licenza [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Questo file è un adattamento (solo
conversione in JSON) ed è distribuito con la stessa licenza.
